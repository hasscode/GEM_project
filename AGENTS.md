## Flutter skill routing

- Before implementing or refactoring Flutter features, read and follow
  `.agents/skills/flutter-feature/SKILL.md`.

- When creating or changing Cubits or state classes, also read and follow
  `.agents/skills/flutter-cubit/SKILL.md`.

- For Flutter code reviews and before reporting implementation complete,
  read and follow `.agents/skills/flutter-code-review/SKILL.md`.

- When asked to draft branch names, commit messages, or PR descriptions,
  read and follow `.agents/skills/flutter-pr/SKILL.md`.
